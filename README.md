# Hypotenuse Calculator
## Description
This calculator assists the user on finding the hypotenuse with the given two sides. This program uses functions like *math.sqrt* and *pow.* Using the *numerical values given by the user* to the program.
## How to Run
This program is required *TWO numerical values* of the two sides of the triangle after each question asked for each value. Then it goes through the solutions to provide the hypotenuse to the user.
## Input Needed
The inputs needed for this calculator is Side A and Side B.
## Sample Output

Enter side A: 18
Enter side B: 21
The hypotenuse is  27.66
